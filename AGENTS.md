# AGENTS.md — PharmAI / RxGuard Portal

Project-specific operating rules. **Read this before touching anything here.**
It overrides the global platform rules where they conflict.

## Scope

Regulatory-aware drug interaction detection for the Indian market. Screens drug
pairs through two lenses at once — pharmacological interaction *and* CDSCO
regulatory status — because a fixed-dose combination can be illegal to dispense
while raising no textbook interaction flag.

- **Live URL:** https://medical.lehana.in/pharmai (mirror: `medical.aidhunik.com/pharmai`)
- **Submission doc:** [HACKATHON_SUBMISSION.md](HACKATHON_SUBMISSION.md)
- **Code:** `/root/repo/pharmai_portal`
- **Docker config:** `/root/docker/pharma-frontend/docker-compose.yml`
- **Elasticsearch:** `/root/docker/rxguard-es/docker-compose.yml`

## Architecture

```
Flask portal (frontend/app.py, container pharma-frontend, port 5000)
  ├── services/elastic_service.py     Elasticsearch: 4 indices, hybrid BM25+kNN+RRF
  ├── services/interaction_agent.py   dual-lens detection pipeline  ← clinical core
  ├── services/fhir_service.py        FHIR R4 Bundle → N×N screen
  ├── services/audit_service.py       append-only SHA-256 hash chain
  ├── services/llm_provider.py        Bedrock Converse | platform fallback
  ├── services/embeddings.py          Titan v2 | local ONNX | hashed floor
  └── services/config.py              all env resolution

rxguard-es (Elasticsearch 8.17.0, container-only + 127.0.0.1:9200)
  rxguard-gazettes      379 CDSCO chunks   rxguard-interactions   8 curated pairs
  rxguard-fhir          ingested resources  rxguard-audit          hash chain
```

**Retrieval always precedes reasoning.** There is no code path where the model
answers without Elasticsearch context. Do not add one.

## Critical Project Rules

1. **Never let the LLM answer ungrounded.** Every verdict must cite retrieved
   Elasticsearch documents. If retrieval is empty, return `unknown` and say what
   is missing. A pharmacovigilance tool that guesses is worse than one that
   admits ignorance.

2. **Never present a fallback answer as an AWS answer.** `LLMResult.degraded` is
   `True` for anything not generated by Bedrock, and that flag must survive all
   the way into the API response and the audit entry. Stripping it is a
   misrepresentation to whoever reads the output.

3. **`banned_fdc` outranks every clinical severity.** A prohibited combination is
   a regulatory fact, not a risk grade. Do not let a model downgrade it because
   only some dosage forms are named in the notification.

4. **Brand names must resolve to salts before lookup.**
   `interaction_agent.BRAND_TO_SALT`. Users type "Nimulid", the gazette says
   "Nimesulide"; without the map the verdict silently degrades from `banned_fdc`
   to `unknown` on exactly the input a real user supplies. Index-time synonyms do
   not fix exact keyword lookups. **Add to this map whenever a new brand appears.**

5. **Changing the embedder requires a reindex.** `EMBED_DIM` must match the `dims`
   the indices were created with. Titan v2 supports 256/512/1024; the local model
   emits 384. Switching to Bedrock means `EMBED_DIM=512` *and* re-running
   bootstrap + ingest. Silently mixing vector spaces corrupts retrieval without
   any error.

6. **Never publish Elasticsearch through Traefik.** `rxguard-es` binds to
   `root_default` and `127.0.0.1:9200` only. There is no router for it and there
   must not be one.

7. **`.env` and every variant is gitignored** (`.env`, `.env.*`, `*.env`). A
   `.env.bak` leaks exactly what the `.env` did. Never commit one; keep backups
   in `/root/backups/pharmai/`.

8. **Sarvam is for speech and OCR only.** Reasoning and retrieval must never move
   back onto Sarvam — that is an external tool replacing an AWS/Elastic core
   capability, which the hackathon rules forbid.

9. **Bind Flask to `0.0.0.0`, not `127.0.0.1`.** Inside a container, loopback
   makes the app unreachable from Traefik. This was a real outage cause.

10. **Never delete `rxguard-es-data`** without the 3-step volume gate. It holds
    the ingested corpus and the entire audit chain.

| # | Flow | Why it exists |
|---|---|---|

## Operational Notes

### Deploy

```bash
cd /root/docker/rxguard-es    && docker compose up -d          # Elasticsearch
cd /root/docker/pharma-frontend && docker compose up -d --build # portal
```

Traefik picks the portal up from Docker labels. **After `docker restart
pharma-frontend`, the Traefik route can 404 for a few seconds** while the Docker
provider re-syncs — retry before assuming a breakage.

### Bootstrap / ingest

Host-side scripts need the loopback ES URL, not the container hostname:

```bash
cd /root/repo/pharmai_portal
set -a && source /root/.secrets/env_files/rxguard-es.env && set +a
ES_URL=http://localhost:9200 .venv/bin/python scripts/bootstrap_elastic.py
ES_URL=http://localhost:9200 .venv/bin/python scripts/ingest_gazettes.py
```

`--recreate` on bootstrap **destroys all indexed data including the audit chain.**

### Activating AWS Bedrock

Add to `frontend/.env` and restart the container:

```
AWS_ACCESS_KEY_ID=…
AWS_SECRET_ACCESS_KEY=…
LLM_PROVIDER=bedrock     # 'bedrock' forbids silent fallback — use for judged runs
EMBED_DIM=512            # Titan v2 geometry; then re-run bootstrap + ingest
```

`config.aws_configured()` validates credentials via STS once per process and
caches the result — stale keys are detected rather than trusted, so a dead
credential does not cost a doomed Bedrock round-trip on every request.

### Known issues

- **4 of 10 gazette PDFs are scanned images** with no text layer, yielding one
  chunk each. Real fix is OCR at ingest (Textract on the AWS path).
- **Flask development server** in production. Needs gunicorn.
- **`/api/medications/screen` is O(n²) LLM calls** — 12 drugs is 66 calls. Capped
  at 12 for that reason.
- Ban classification is regex-based; precision is good, recall unmeasured against
  a labelled set.
