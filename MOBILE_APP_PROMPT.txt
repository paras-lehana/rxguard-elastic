API 1: SEARCH MEDICINE STATUS (PRIMARY FEATURE)
══════════════════════════════════════════════

Endpoint: POST /api/search

Request Body:
{
  "query": "Is paracetamol banned in India?",
  "sessionId": "mobile-session-12345"
}

Response Structure:
{
  "query": "dolo 650",
  "medicine_searched": "Paracetamol (active ingredient in Dolo 650)",
  "current_status": "open",
  "results": {
    "summary": "Paracetamol is not banned...",
    "drug_category": "single_drug",
    "schedule_classification": "Not Scheduled",
    "controlled_status": "Not controlled",
    "source_authority": "CDSCO",
    "date_of_ban": "N/A",
    "date_of_uplift": "N/A",
    "gazette_id": "N/A",
    "act_reference": "N/A"
  },
  "sessionId": "mobile-session-12345"
}

🎨 CRITICAL UI/UX REQUIREMENTS FOR RESULTS SCREEN:

1. MEDICINE NAME (Header - Bold, Large)
   Display: medicine_searched
   Example: "Paracetamol (active ingredient in Dolo 650)"

2. STATUS BADGE (Most Prominent Visual)
   Display: current_status
   
   Color-coded badges:
   • current_status = "open" → Green badge "✅ ALLOWED"
   • current_status = "banned" → Red badge "🚫 BANNED"  
   • current_status = "restricted" → Orange badge "⚠️ RESTRICTED"

3. SUMMARY (Primary Answer - Most Important)
   Display: results.summary
   This field contains the complete answer in plain English
   Show in prominent card/section with good readability
   This is the MAIN CONTENT users need to see

4. REGULATORY DETAILS (Secondary - Expandable)
   Display these fields ONLY if value is NOT "N/A" or "Not specified in documents":
   • results.drug_category → "Drug Category"
   • results.schedule_classification → "Schedule Class"
   • results.controlled_status → "Controlled Status"
   • results.source_authority → "Authority"
   • results.date_of_ban → "Ban Date"
   • results.date_of_uplift → "Uplift Date"
   • results.gazette_id → "Gazette ID"
   • results.act_reference → "Act Reference"

API 2: UPLOAD & INDEX DOCUMENT
═══════════════════════════════

Endpoint: POST /api/index
Content-Type: multipart/form-data

Form Fields:
- file: PDF file (required)
- metadata: JSON string (optional)

Example metadata:
{
  "source": "CDSCO",
  "type": "banned_drugs_list",
  "year": "2024"
}

Response:
{
  "message": "Document indexed successfully",
  "result": {
    "done": true,
    "response": {
      "documentName": "fileSearchStores/abc123/documents/xyz789"
    }
  }
}

UI Display:
- Show upload progress indicator
- Display success message: "Document uploaded and indexed successfully"

═══════════════════════════════════════════════════════════════════════════════

API 3: LIST ALL DOCUMENTS
══════════════════════════

Endpoint: GET /api/documents

Response:
{
  "documents": [
    {
      "name": "fileSearchStores/.../xyz789",
      "displayName": "banned-drugs-cdsco-2024.pdf",
      "mimeType": "application/pdf",
      "sizeBytes": 34703,
      "createTime": "2026-02-16T10:30:00Z",
      "updateTime": "2026-02-16T10:30:00Z",
      "metadata": [
        {"key": "source", "stringValue": "CDSCO"},
        {"key": "type", "stringValue": "banned_drugs_list"}
      ],
      "state": "ACTIVE"
    }
  ],
  "total": 1
}

UI Display for Each Document:
1. File Name: displayName
2. File Size: Convert sizeBytes to KB/MB (e.g., "34.7 KB")
3. Upload Date: Format createTime as readable date
4. Source: Extract from metadata array (key: "source")
5. Status: state (ACTIVE = green badge)

}

{
  "message": "Document deleted successfully",
  "document": {
    "name": "fileSearchStores/abc123/documents/xyz789",
    "displayName": "banned-drugs-cdsco-2024.pdf"

}

UI Requirements:

- Refresh document list

🚀 QUICK START CODE (JavaScript/TypeScript):

const searchMedicine = async (query) => {
  const response = await fetch('https://medical.lehana.in/ncert/api/search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      query: query,
      sessionId: 'mobile-' + Date.now()
    })
  });
  
  const data = await response.json();
  
  return {
    medicineName: data.medicine_searched,
    status: data.current_status,        // "open", "banned", "restricted"
    summary: data.results.summary,      // MOST IMPORTANT - show prominently
    details: data.results                // All regulatory details
  };
};
